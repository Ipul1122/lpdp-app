# Panduan Dokumentasi Tangkapan Layar (Screenshots)

Folder ini berfungsi sebagai repositori aset visual (*screenshots*) aplikasi **LPDP / TUBEL App** untuk melengkapi dokumentasi teknis, buku panduan, serta file `README.md` utama pada repositori.

---

## 📸 Standar Pengambilan Tangkapan Layar

1. **Resolusi & Skala Layar:**
   - Resolusi standar yang digunakan: **1440 × 900 / 1920 × 1080**.
   - Skala perbesaran (*browser zoom*): **100%**.
2. **Format & Penamaan File:**
   - Format: **PNG** (kualitas tampilan tajam & presisi).
   - Penamaan terstruktur dengan penomoran urut (`01-`, `02-`, dst.).
3. **Data Pengujian:**
   - Menggunakan data pengujian realistis dari database dan alur multi-step wizard.

## 💡 Cara Menyematkan Gambar ke `README.md` Utama

Untuk menampilkan gambar di file `README.md` utama pada repositori:

### 1. Menampilkan Gambar Tunggal:
```markdown
### Dashboard Administrator
![Dashboard Administrator](screenshots/22-admin-dashboard.png)
```

### 2. Menampilkan Gambar Berdampingan (Tabel 2 Kolom):
```markdown
| Alur Step 1 (Profil & KTP) | Alur Step 7 (Ringkasan & Kirim) |
| :---: | :---: |
| ![Tahap 1](screenshots/10-step1-profil-ktp.png) | ![Tahap 7](screenshots/16-step7-ringkasan-finalize.png) |
```
